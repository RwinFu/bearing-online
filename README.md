# برینگ آنلاین — Bearing Online

فروشگاه/پلتفرم جستجو و تامین سریع قطعات صنعتی (SPA استاتیک، **بدون بیلد و بدون npm**).

## اجرا

فایل‌ها به‌صورت نسبی لینک شده‌اند؛ فقط یک سرور استاتیک ساده لازم است:

```bash
python3 -m http.server 8080
# سپس http://localhost:8080
```

> باز کردن مستقیم `index.html` با `file://` هم کار می‌کند، ولی چون سایت از `history.pushState`
> برای مسیریابی استفاده می‌کند، اجرای روی سرور استاتیک توصیه می‌شود.

## نکته‌ها

- **ترتیب لود JS مهم است**؛ فایل‌ها به هم وابسته‌اند (گلوبال). فایل جدید را قبل از `17-init.js` اضافه کنید.
- فیلدهای مشتق‌شدهٔ محصولات (کد نرمال‌شده، وضعیت موجودی، قیمت تومانی، ابعاد بسته‌بندی…) در تابع
  `hydrateProductDatabase()` و از داخل `17-init.js` ساخته می‌شوند — نه در زمان لود `01-state-data.js` —
  چون آن هلپرها (مثل `normalizePartCodeDisplay`) در فایل‌های بعدی تعریف شده‌اند.
- **هیچ CDN خارجی لازم نیست**: Tailwind v4 (browser build)، Three.js r128، Font Awesome 6.4 و فونت‌های
  Vazirmatn/Inter همه در `assets/vendor/` لوکال هستند (جزئیات و نسخه‌ها در `assets/vendor/README.md`).
- تنها منابع اینترنتی باقی‌مانده «تزئینی» هستند و در صورت نبود اینترنت، سایت خراب نمی‌شود:
  QR پیگیری در پیش‌فاکتور، لینک واتس‌اپ و دکمهٔ دیتاشیت محصول (در تب جدید باز می‌شود؛
  SKF به جست‌وجوی رسمی خودش و بقیهٔ برندها به جست‌وجوی هدفمند دیتاشیت می‌روند).
  لوگوی هدر و فوتر وکتور محلی ثابت است.
- **تامین‌کنندهٔ هر سطر سبد دادهٔ داخلی است**: روی `data-supplier` سطر سبد و اسنپ‌شات سفارش
  می‌ماند و در پنل عملیات دیده می‌شود، ولی در سبد خرید و تسویهٔ مشتری نمایش داده نمی‌شود.
- **پاسخ درخواست‌های مشتری همیشه یک مقصد دیدنی دارد**: استعلام قیمت، مشاوره مهندسی، ثبت سریع
  قطعه و جستجوی ناموفق در `AppState.leads` ثبت می‌شوند و با کد پیگیری، وضعیت و پاسخ کارشناس در
  صفحه «سفارش‌ها ← درخواست‌های من» (`renderAccountLeads`) فهرست می‌شوند؛ استعلام‌های سبد هم در
  «استعلام قیمت اقلام (RFQ)» (`renderAccountRFQs`).
- افکت هاور متن فقط روی تیتر هیرو (`[data-vector-title]`) فعال است؛ لایه وکتور سراسری صفحه اول
  به‌دلیل کندی حذف شده است.
- سایت به WebGL وابسته نیست: اگر مرورگر/دستگاه WebGL نداشته باشد، استیج سه‌بعدی به
  `#bearingFallback` می‌افتد و بقیهٔ صفحه سالم می‌ماند.

## تست

```bash
cd tools/smoke-test && npm install && npm test
```

تست ساختاری (cross-reference مارک‌آپ و JS) + تست اجرایی با jsdom روی ۵۵ جریان کاربری؛ به‌علاوه ۳۹ بررسی مرورگر واقعی برای چیدمان و تعامل.
جزئیات: [`tools/smoke-test/README.md`](tools/smoke-test/README.md)

### تست مرورگر واقعی (اختیاری)

سرور سایت را روشن نگه دارید، سپس در ترمینال دوم:

```bash
cd tools/smoke-test
npm ci
npx playwright install chromium
npm run test:browser
```

پیش‌فرض تست مرورگر `http://127.0.0.1:8080` است؛ با `BASE_URL` قابل تغییر است.
این آدرس فقط برای ابزار تست داخل محیط توسعه استفاده می‌شود؛ سایت به سرویس localhost وابسته نیست.
خروجی تصویری تست‌ها در `.arena/browser-audit/` ذخیره می‌شود و وارد Git نمی‌شود.

## محدودیت داده و فروش

کاتالوگ فعلی شامل **۳۳ محصول نمونهٔ محلی** است. سفارش، موجودی و پرداخت همچنان mock هستند؛
اصلاح جستجو و ظاهر، اتصال به انبار واقعی، سرور فروش یا درگاه پرداخت ایجاد نمی‌کند.
نمای بلبرینگ در «درباره ما» یک مدل تعاملی نمایشی است، نه فایل CAD یا نقشهٔ ساخت سازنده.
