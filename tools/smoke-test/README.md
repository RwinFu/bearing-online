# tools/smoke-test — تست دودی (اختیاری)

این پوشه **بخشی از سایت نیست** و به مرورگر ارسال نمی‌شود؛ فقط برای اطمینان از سالم بودن
ساختار فایل‌ها بعد از هر تغییر است. سایت خودش بدون بیلد و بدون npm اجرا می‌شود.

## اجرا

```bash
cd tools/smoke-test
npm ci          # وابستگی‌های تست، جدا از سایت
npm test
```

## چه چیزی تست می‌شود؟

`static-check.js` (بدون نیاز به مرورگر):

- هر تابعی که در `onclick`/`onchange` مارک‌آپ صدا زده می‌شود، در یکی از ۱۷ فایل JS تعریف شده باشد.
- هر `getElementById` در JS، به یک المان موجود (در HTML یا در تمپلیت‌های خود JS) اشاره کند.
- همهٔ فایل‌های محلی `src`/`href` روی دیسک موجود باشند و هر ۱۷ ماژول در `index.html` با ترتیب درست لود شوند.
- `index.html` فقط یک `</head>` داشته باشد.

`run.js` (jsdom، بدون GPU):

- سایت را روی یک HTTP محلی سرو می‌کند و `index.html` را با اجرای واقعی `<script>`ها بالا می‌آورد.
- جریان‌ها را اجرا می‌کند: جستجو (کد، برند، ابعادی، کلیرنس، فارسی) → محصول → سبد → تسویه →
  پرداخت mock → پیش‌فاکتور → پنل سفارش‌ها → پنل عملیات (RBAC) → لید → شکایت → مقایسه/علاقه‌مندی →
  صفحه برندها → تعویض زبان → مسیریابی hash.
- انتظار دارد صفر خطای JS ثبت شود و صفحهٔ سه‌بعدی، وقتی WebGL نیست، به fallback بیفتد.

> jsdom موتور رندر/چیدمان نیست؛ پس ظاهر و CSS اینجا تست نمی‌شود. برای تست ظاهر، سایت را در مرورگر باز کنید.


## رگرسیون‌های جستجو و نمایش سه‌بعدی

`npm test` اکنون ۴۵ بررسی اجرایی دارد، شامل ارقام فارسی/عربی، ترتیب کد و برند،
پسوند و کلیرنس ترکیبی، اعتبارسنجی ابعاد، فیلتر تمام برندهای کاتالوگ، حفظ وضعیت در URL،
عدم دست‌کاری ترتیب دیتابیس با sort، جلوگیری از درج HTML جستجو، کیبورد autocomplete و fallback سه‌بعدی.

### مرورگر واقعی

با سرور استاتیک روشن روی پورت 8080:

```bash
npx playwright install chromium
npm run test:browser
```

متغیرهای اختیاری: `BASE_URL` برای نشانی سرور و `CHROMIUM_EXECUTABLE_PATH` برای مرورگر ازپیش‌نصب‌شده.

۳۹ بررسی در Chromium:
- خانه، نتایج، برندها، خدمات، تماس و درباره ما در عرض‌های 320، 390، 768، 1024 و 1440 پیکسل؛
- منوی موبایل و مدیریت فوکوس، انتخاب پیشنهاد با کیبورد، Back، reload و حفظ نمای جدول؛
- عدم هم‌پوشانی دکمه‌های کارت و اسکرول محلی جدول؛
- چیدمان انگلیسی و صفحات محصول، سبد پر، مقایسه، علاقه‌مندی، تسویه و سفارش‌ها؛
- رندر واقعی WebGL، حالت‌های مدل، زوم، reset، کیبورد، reduced motion و توقف رندر در صفحهٔ پنهان.

اسکرین‌شات‌ها در `.arena/browser-audit/` (خارج از Git) ذخیره می‌شوند.
تست مرورگر به پشتیبانی WebGL نیاز دارد؛ مسیر بدون WebGL جداگانه با jsdom تست می‌شود.
شبیه‌سازی عرض صفحه جای تست روی سخت‌افزار واقعی iOS/Android یا Safari را نمی‌گیرد.

### راهنمای ارسال و مرجوعی

تست اجرایی `node run.js` مسیر `#/shipping`، هشت بخش سیاست ارسال و مرجوعی،
لینک‌های صفحه اصلی و فوتر، مسیر تماس با پشتیبانی و ترجمه فارسی/انگلیسی محتوای جدید را بررسی می‌کند.
تست hash به‌جای تأخیر ثابت، منتظر نمایان شدن صفحه مقصد می‌ماند.
