# tools/smoke-test — تست دودی (اختیاری)

این پوشه **بخشی از سایت نیست** و به مرورگر ارسال نمی‌شود؛ فقط برای اطمینان از سالم بودن
ساختار فایل‌ها بعد از هر تغییر است. سایت خودش بدون بیلد و بدون npm اجرا می‌شود.

## اجرا

```bash
cd tools/smoke-test
npm install     # فقط jsdom
npm test
```

## چه چیزی تست می‌شود؟

`static-check.js` (بدون نیاز به مرورگر):

- هر تابعی که در `onclick`/`onchange` مارک‌آپ صدا زده می‌شود، در یکی از ۱۷ فایل JS تعریف شده باشد.
- هر `getElementById` در JS، به یک المان موجود (در HTML یا در تمپلیت‌های خود JS) اشاره کند.
- همهٔ فایل‌های محلی `src`/`href` روی دیسک موجود باشند و هر ۱۷ ماژول در `index.html` با ترتیب درست لود شوند.
- `index.html` فقط یک `</head>` داشته باشد.

`run.js` (jsdom، بدون GPU):

- سایت را روی یک HTTP محلی سرو می‌کند و `index.html` را با اجرای واقعی `<script>`ها بالا می‌آورد.
- جریان‌ها را اجرا می‌کند: جستجو (کد، برند، ابعادی، کلیرنس، فارسی) → محصول → سبد → تسویه →
  پرداخت mock → پیش‌فاکتور → پنل سفارش‌ها → پنل عملیات (RBAC) → لید → شکایت → مقایسه/علاقه‌مندی →
  صفحه برندها → تعویض زبان → مسیریابی hash.
- انتظار دارد صفر خطای JS ثبت شود و صفحهٔ سه‌بعدی، وقتی WebGL نیست، به fallback بیفتد.

> jsdom موتور رندر/چیدمان نیست؛ پس ظاهر و CSS اینجا تست نمی‌شود. برای تست ظاهر، سایت را در مرورگر باز کنید.
